WHY THIS HELPS

A regular prompt or saved skill can describe either layout. JSON is useful
when you want to keep recurring choices in separate settings files. Here,
you switch the layout filename instead of restating the column list and
formatting. Copilot still needs to read the files and you still check its work.

OPTIONAL: CHANGE ONE HEADING

1. Open references/manager-layout.json inside your INSTALLED OneDrive
   variance-review-json folder. Editing a spare copy in Downloads will not
   update the installed skill.
2. Find "field": "Variance" and the "header": "Vs budget" beside it.
3. Change only "Vs budget" to "Change vs plan". Keep "Variance", quotes,
   commas and braces as they are. Keep the rest of the complete file.
4. Save the existing .json file, not a new .txt copy. Let OneDrive sync,
   refresh skills and send UPDATE MANAGER below.
5. Check: new heading, same eight rows, same amounts. If the heading stays
   the same, check that you edited the installed copy and Copilot read it.

The saved workbook and screenshots show the original "Vs budget" heading.
You can change the heading back in the JSON file and rerun UPDATE MANAGER.
